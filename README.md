# Candyland

A Java implementation of the Candyland board game developed as an academic programming project.

The project uses a custom doubly linked list to represent movement along the game board and JavaFX/FXML for the graphical interface.

## Features

- Candyland-style board movement
- Randomized color spinner
- Multiple player objects
- Forward and backward board traversal
- Custom doubly linked list implementation
- JavaFX graphical interface
- Event-driven game controls

## Technologies

- Java
- JavaFX
- FXML
- Maven
- Data structures
